\begin{abstract}
This paper presents an autonomous maze-navigation system for a differential-drive mobile robot
equipped with a 360° LiDAR, wheel encoders, and an RGB camera for ArUco marker detection.
The SLAM pipeline combines an occupancy grid with Gauss-Newton scan matching and Monte Carlo
localization (MCL). A PCA-guided corridor follower with junction detection handles maze
traversal, while a Dynamic Window Pure Pursuit (DWPP) navigator was developed for general
navigation. The robot escaped the $8{\times}8$ cell evaluation maze with a best time of ~30\,s
including ArUco treasure collection.
\end{abstract}
